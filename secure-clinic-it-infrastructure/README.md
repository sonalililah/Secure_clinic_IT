# Secure Clinic IT Infrastructure

## Overview

This project implements a secure, scalable healthcare IT infrastructure for a small clinic using Microsoft Azure and Microsoft security technologies.

The solution provides:

- Active Directory Domain Services
- Microsoft Entra ID
- Role-Based Access Control (RBAC)
- OpenVPN Remote Access
- Multi-Factor Authentication (MFA)
- Microsoft Intune
- Windows Defender Firewall
- Azure Virtual Network
- Security Monitoring
- Audit Logging
- Backup Validation

---

## Objectives

- Protect sensitive healthcare information
- Centralize identity and access management
- Provide secure remote access
- Improve network security
- Support healthcare security best practices
